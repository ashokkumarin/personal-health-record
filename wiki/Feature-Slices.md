# Feature Slices

PHR was built using spec-driven, slice-by-slice development: each slice states its own acceptance criteria, a test list written before implementation, and a definition of done. See [MVP Spec](MVP-Spec) Section 7 for the general workflow and [Technical Design](Technical-Design) for the as-built architecture these slices produced.
